# 文档索引

项目相关资料统一放在本目录，建议按以下结构维护：

```text
docs/
|-- competition/        # 赛题、比赛规则和结果材料
|-- hardware/           # 原理图、PCB、器件资料和接线说明
|-- protocol/           # 通信协议与固件升级协议
|-- images/             # README 和文档使用的图片
`-- README.md           # 本索引
```

## 收录规则

每份外部材料应在下表中记录来源和授权状态。只有确认允许公开再分发后，才将文件提交到仓库；否则只保留官方来源链接。

| 文件 | 类别 | 版本/日期 | 来源 | 授权状态 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 待补充 | - | - | - | 待确认 | - |

## 文件命名

- 使用能表达内容和版本的名称，例如 `cimc-2026-embedded-preliminary-task.pdf`。
- 尽量避免 `最终版`、`新建文档`、`副本` 等无法追踪版本的名称。
- 图片建议使用 PNG、JPEG、WebP 或 SVG；可搜索的文档优先保留 PDF 文本层。

## 大文件

普通 PDF 和图片不会被 `.gitignore` 排除。若单个文件较大或经常替换，建议使用 Git LFS；发布包、演示视频和固件二进制更适合放在 GitHub Release，避免永久膨胀 Git 历史。
