# 官方初赛资料包

本目录保留赛事发布资料的原始结构，便于复现 2026 年 CIMC 工业嵌入式系统开发方向初赛环境。

## 主要内容

- `1 2026年CIMC工业嵌入式系统开发 初赛 赛题.pdf`：正式赛题。
- `2 2026CIMC工业嵌入式系统开发 初赛 上位机（正式比赛版）.exe`：官方比赛上位机。
- `3 2026年CIMC工业嵌入式系统开发（试）工程设计文件模板.docx`：工程设计文件模板。
- `4 2026年CIMC工业嵌入式系统开发（试）初赛PPT模板.pptx`：答辩 PPT 模板。
- `LocalBuild/`：本地评测程序、运行依赖、配置和评测结果转换工具。
- `固件文件/`：官方测试固件及其说明。
- `赛题提取文本.txt`：赛题的纯文本辅助版本。

## 使用说明

这些可执行文件和依赖库不属于本项目原创源码。运行前请确认文件来源，并在可信或隔离环境中使用。`LocalBuild/` 的内部目录和文件名保持原样，不做依赖裁剪，以避免破坏官方评测程序。

本目录内容不适用仓库根目录的 MIT License，版权和使用条件以赛事组织方的原始发布说明为准。
