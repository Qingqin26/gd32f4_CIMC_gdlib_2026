# 文档索引

项目相关资料按来源和用途分为三类：

```text
docs/
|-- competition/        # 官方赛题、说明、模板和比赛工具
|-- submissions/        # 队伍编号 2026837587 的提交材料
|-- hardware/           # 芯片数据手册与评估板资料
`-- README.md           # 本索引
```

## 赛事官方资料

位于 [`competition/`](competition/README.md)：

- `初赛说明-v20260306.pdf`：初赛安排、提交要求和时间说明。
- `初赛硬件设计题目说明.pdf`：硬件设计任务与验收要求。
- `official-package/`：赛事发布的初赛赛题、上位机、设计文档模板、PPT 模板、本地评测环境和测试固件。

`official-package/LocalBuild/` 包含可执行文件、依赖库、数据库和评测结果转换工具，体积较大。其内容用于复现官方比赛环境，不属于本项目原创源码。

## 队伍提交材料

位于 [`submissions/`](submissions/README.md)：

- `2026837587-dsn.pdf`：队伍 2026837587 的全国初赛工程设计文件，共 42 页。
- `2026837587-pptx.pptx`：队伍 2026837587 的系统介绍与答辩演示文稿。

## 硬件参考资料

位于 [`hardware/`](hardware/README.md)：

- GD30AD3344 ADC 数据手册和评估板用户指南。
- GD30DC1354 降压转换器英文数据手册及非官方机器翻译稿。

## 文件命名

- 使用能表达内容和版本的名称。
- 尽量避免 `最终版`、`新建文档`、`副本` 等无法追踪版本的名称。
- 官方资料包内部文件保留原始名称，便于与赛事发布内容核对。

## 大文件

当前官方资料包包含较大的 EXE、DLL 和 PDB 文件。后续若此类文件频繁更新，应改用 Git LFS 或 GitHub Release，避免永久膨胀 Git 历史。
